# GitHub Features

1. Repositories – Store project files and version history.
2. Branches – Work on features separately without affecting main code.
3. Pull Requests – Propose changes and review code before merging.
4. Issues – Track bugs, tasks, and feature requests.
5. Actions – Automate workflows using CI/CD.
6. Projects – Manage tasks using Kanban boards.
7. Releases – Publish stable versions of software.
8. Forking – Copy repositories to contribute independently.
9. Security Alerts – Detect vulnerabilities in dependencies.
